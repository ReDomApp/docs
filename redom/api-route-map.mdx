The authoritative route registry is `artifacts/redom-backend/src/routes/index.ts`. The registry imports feature modules and mounts them on the Express router. This page maps the mounted groups; exact HTTP methods, paths, schemas, status codes, and authentication rules must be read from each route module.

## Messaging module inventory

The route registry mounts separate modules for encrypted media, forwarded media, shared messaging, message media, completion/lifecycle, group schema bootstrap, group details, invite permissions, scheduled group calls, group management, approvals, send guards, messaging guards, E2EE, conversation cryptography, forwarding, chat information, linked-device links, drafts, read receipts, inbox, group reports, and core messages.

## Contract extraction standard

For each endpoint, document:

- Method and fully mounted path (including parent router prefix).
- Authentication and authorization middleware.
- Request parameters, body schema and validation.
- Response schema and representative success/error codes.
- Idempotency, pagination, rate limits and ownership checks.
- Side effects, database tables and external provider calls.

Do not infer a public endpoint merely from an imported filename. Source links: [route registry](https://github.com/ReDomApp/redom-backend/blob/main/artifacts/redom-backend/src/routes/index.ts) and [route directory](https://github.com/ReDomApp/redom-backend/tree/main/artifacts/redom-backend/src/routes).
