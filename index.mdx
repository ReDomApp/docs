## Source of truth

- Master engineering repository: [ReDomApp/redom-backend](https://github.com/ReDomApp/redom-backend), branch `main`.
- Documentation repository: [ReDomApp/docs](https://github.com/ReDomApp/docs), branch `main`.

The backend repository is the implementation source. This repository is the documentation output. Documentation changes must not modify product code, deployments, production databases, provider accounts, or infrastructure.

## Accuracy and status

Each page distinguishes source-implemented behavior from configured runtime dependencies, incomplete work, and planned capabilities. A route or worker in source does not prove that its production deployment or external provider connection is operational.

Secrets, credentials, customer personal data, payment credentials, and sensitive runtime values are never published.
