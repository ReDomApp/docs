## How this knowledge base works

- **Central during development:** AUREVON GROUP maintains the shared documentation workspace.
- **Product-specific knowledge:** ReDom, Aurelink, and other products have distinct sections.
- **Source-backed accuracy:** Implementation claims must be verified against current source, schemas, API definitions, and deployment configuration.
- **Independent future documentation:** Products may move to their own documentation sites when ready. The parent site retains corporate-level information and links.

## Important boundary

This site is for documentation. Repository access should be read-only wherever possible. Documentation work must not modify application source, deploy products, change production databases, or operate payment and infrastructure systems.
